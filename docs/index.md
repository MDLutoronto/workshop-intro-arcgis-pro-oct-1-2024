# Workshop Recording: An Introductory Tour of ArcGIS Pro (Oct. 1, 2024)

This page provides a video recording of an introductory workshop on ArcGIS Pro.

**Workshop Description:**

WHAT TO EXPECT

* Installation and Setup: We’ll start with a step-by-step guide on how to install ArcGIS Pro, a powerful, industry-standard desktop GIS software.
* Navigating the Interface: Get familiar with the different parts of the ArcGIS Pro interface, making it easier to find the tools and features you need.
* Exploring Datasets: Learn how to import and explore datasets, unlocking the potential of spatial data analysis.
* Symbology: Discover how to apply basic symbology, turning data into cartographic visualizations.
* Exporting Maps: Export your maps to PDF, allowing you to share your work with others and incorporate your mapping into print products such as reports and posters.
* Resources: Learn about ongoing support that the Map and Data Library can provide: assistance finding data, one-on-one consults with subject matter experts, and access to specialized software.

In addition to these practical skills, we’ll also cover the fundamentals of GIS, including an overview of different file formats such as raster and vector data. If you'd like to learn how to use spatial analysis in your studies and research, this workshop is the perfect starting point. Don’t miss this opportunity to enhance your GIS skills and take your first steps with ArcGIS Pro.

UofT Libraries provides a free license for ArcGIS Pro. To obtain the software, follow the instructions here: <a href="https://mdl.library.utoronto.ca/technology/tutorials/downloading-installing-and-licensing-arcgis-pro">https://mdl.library.utoronto.ca/technology/tutorials/downloading-installing-and-licensing-arcgis-pro</a>. Please note that ArcGIS Pro is Windows-only. If you don't have Windows, you can use the software on campus (see <a href="https://mdl.library.utoronto.ca/technology/computers-with-gis-software">https://mdl.library.utoronto.ca/technology/computers-with-gis-software</a>).
